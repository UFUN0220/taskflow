# 阶段 13：前端基础功能

阶段 13 将已有后端 API 接入 React + TypeScript + Vite 前端，目标是让核心流程可以通过页面完成。页面保持简单，重点是权限边界、错误处理、状态同步和写操作防重复提交。

## 已实现流程

- 登录、退出和 Token 持久化；401 自动清理 Token 并回到登录页；
- 工作台项目列表和项目创建；
- 任务列表、状态/优先级过滤、任务创建、草稿编辑/删除、任务详情、状态操作和负责人转交；
- 任务评论和附件上传/删除；
- 通知中心 HTTP 补拉、已读、全部已读和 WebSocket 实时通知；
- 用户、角色、部门基础管理；用户状态和角色分配；角色权限编码与数据范围配置；
- 菜单和操作按钮根据当前用户权限显示。

## 前端边界

`frontend/src/api.ts` 统一处理 API 响应、Bearer Token、401、业务错误和 traceId。按钮隐藏只用于用户体验，所有权限和数据范围仍由后端 `PreAuthorize`、业务服务和数据权限逻辑执行。

所有写操作使用 Ant Design 的 loading 状态或统一 busy 状态防止重复提交；发生版本冲突时保留后端错误提示，用户可刷新详情后重试。
