# 阶段 0-1 学习笔记

1. 阶段 0 的目标是建立可验证的运行边界，不提前实现业务模块。
2. Compose 中使用宿主机非默认端口，减少与本机已有服务冲突的概率；应用容器内部仍使用容器端口。
3. 基础设施健康检查只能说明服务进程可用，不能替代后续数据库迁移、连接池和业务集成测试。
4. 当前健康接口开放访问只是启动验收需要，后续认证阶段必须重新定义安全边界。
5. 数据库索引应从列表、详情、调度和审计查询反推，而不是为每个字段机械建索引。
6. `task_operation_log` 与 `audit_log` 都是日志，但前者描述任务领域变化，后者描述跨模块安全审计，不能用一张表混合。
7. 状态机的命令语义必须避免同一条边被多个含义相同的动作覆盖；本设计用 `accept` 和驳回后的 `start` 区分场景。
8. Flyway 脚本只负责结构演进，默认账号和权限种子应在认证/权限阶段以可审计方式加入。
